# Taller de Lenguajes de Marcado y Tecnologías Web

**1er Cuatrimestre 2026 - Proyecto "RescatAR"**

Proyecto web institucional desarrollado para el rescate, cuidado y adopción responsable de animales en situación de calle. 

* **Institución:** Universidad Nacional de Hurlingham (UNAHUR)
* **Comisión:** Comisión 2 (Miércoles - Turno Tarde)

---

## 📄 Descripción

Este sitio web fue diseñado y desarrollado para presentar la información oficial de **RescatAR**, una ONG dedicada al rescate de animales abandonados. El objetivo de la plataforma es promover la adopción responsable, difundir los programas de asistencia veterinaria, concientizar a la comunidad y centralizar las solicitudes de contacto y voluntariado a través de una interfaz limpia, moderna y accesible.

---

## 🚀 Tecnologías Utilizadas

* **HTML5:** Estructuración semántica del contenido de todo el sitio.
* **CSS3:** Estilos personalizados, paleta de colores corporativa y diseño adaptativo.
* **Bootstrap 5.3.3:** Framework ágil para componentes como la barra de navegación responsive y el sistema de grillas.
* **Google Fonts:** Tipografía "Poppins" para mejorar la legibilidad y estética visual.
* **Git y GitHub:** Control de versiones y trabajo colaborativo.
* **Visual Studio Code:** Entorno de desarrollo integrado.

## 📂 Estructura del Proyecto

El proyecto está organizado de forma modular con las siguientes páginas y directorios:

```text
├── index.html          # Página de inicio (Quiénes somos y vista general de programas)
├── nosotros.html       # Historia de la ONG, valores institucionales y staff

├── css/
│   └── estilos.css     # Archivo central de estilos personalizados y variables CSS
├── java/
│   └── scriptRescatAR.js # Lógica de interacción y validaciones del sitio
└── img/                # Repositorio de recursos visuales e imágenes del proyecto
